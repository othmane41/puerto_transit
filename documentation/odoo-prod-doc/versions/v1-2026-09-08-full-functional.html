Limites de vérification

Le guide reste publiable avec les limites explicitement constatées suivantes :

  • Documentation complète du code Git de production exact avec limitations runtime documentées.
  • Le runtime partagé ptmaroc ne permet aucune affirmation d’installation, rôle, écran, donnée, résultat ou transition pour origin/main.
  • Chaque surface candidate est documentée sans capture avec des preuves Git statiques exactes.
